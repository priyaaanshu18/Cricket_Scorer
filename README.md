# 🏏 RCC Scorer

A web-based cricket scoring application built using HTML, CSS and JavaScript.

## 🚀 Features

- Limited Overs & Test Match support
- Ball-by-ball scoring
- Wickets and extras
- Player & bowler statistics
- Match history
- Undo scoring
- Follow-on & declaration support
- Mobile-friendly UI

## 🛠️ Tech Stack

HTML • CSS • JavaScript • Local Storage

## ▶️ Run

Open `index.html` in a browser or use VS Code Live Server.
